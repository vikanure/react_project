1. Створіть простий відеохостинг на Node.js з використанням Express. Реалізуйте фронтенд на React для відображення відео.
2. Додайте можливість завантаження та перегляду відео. Реалізуйте систему коментування відео.
3. Реалізуйте систему користувачів та управління їхніми правами. Додайте функціонал "Поділитися відео", щоб користувачі могли надсилати відео іншим користувачам.
4. Оптимізуйте систему для високих навантажень. Реалізуйте систему підписки на канали та повідомлень про нові відео.
